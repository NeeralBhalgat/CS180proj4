# CS180 Project 4: Image Mosaicing

Website: https://neeralbhalgat.github.io/CS180proj4/

Install dependencies:

```sh
python3 -m pip install -r requirements.txt
```

Run all Part A and Part B results:

```sh
python3 main.py
```

Run Part B only, or one section:

```sh
python3 proj4b.py
python3 proj4b.py --part b4
```

The current source files match the local submission/code package. Harris detection
uses the supplied harris.py. Input photos and correspondence files are in images/;
outputs are written to results/ and results/part_b/.

requirements-b.txt is retained as an alias for the dependency file named in the report.
